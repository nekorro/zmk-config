# Alt+Tab на слое Nav Dig

Изменение подготовлено для ветки `ruen-hm-opt`, ZMK `v0.3.0`.

- Удерживание `MO4` включает обычный слой `Nav Dig`.
- До первого нажатия бывшего Scroll Lock Alt не нажимается: навигация,
  цифры и остальные сочетания слоя работают как раньше.
- Первое нажатие бывшего Scroll Lock нажимает левый Alt, затем Tab.
- Отпускание этой клавиши отпускает только Tab. Повторные нажатия
  переключают окна, пока удерживается `MO4`. Обе существующие клавиши
  Tab тоже позволяют продолжать переключение.
- Отпускание `MO4` отпускает Alt, даже если Tab ещё удерживается.

После начала переключения Alt удерживается до отпускания `MO4`, как на
обычной клавиатуре. Поэтому другие клавиши, нажатые в этот промежуток,
также видят удерживаемый Alt. Чтобы вернуться к обычной навигации,
отпустите и снова нажмите `MO4`.

## Установка

Изменение уже включено в ветку `ruen-hm-opt`. После успешной сборки этой
ветки в GitHub Actions скачайте артефакт `firmware`.

Workflow ZMK `v0.3.0` автоматически подключает локальный модуль при наличии
`zephyr/module.yml`; одного файла `totem.keymap` для сборки недостаточно.

В текущей конфигурации центральное устройство — донгл. Обновите его
прошивкой `dongle-screen.uf2`. Для этой правки не требуется сбрасывать
настройки Bluetooth. При другой схеме подключения обновлять нужно устройство,
которое выполняет роль central.

## Реализация

`&nav_alt_tab` отправляет обычные события ZMK для `LALT` и `TAB`.
Модуль хранит собственное состояние Alt, нажимает его один раз за сеанс
и отпускает по событию деактивации слоя 4. Это сохраняет счётчик
модификатора при одновременном использовании отдельного Alt.

Обе клавиши `&mo LAYER_NAV_DIG` в английском и русском слоях включают слой 4.
Таймеров, стороннего форка ZMK и изменений на компьютере не требуется.

Тест в `tests/nav-alt-tab` использует настоящую раскладку и mock scanner
ZMK. Проверено: сборка для `native_posix_64` и восемь сценариев проходят
на ZMK `v0.3.0`; все 46 ожидаемых событий совпали. На исходной раскладке
этот же тест обнаруживает Scroll Lock вместо Alt+Tab. Проверено также
применение патча к коммиту `767775848bf88493faa6fce02ac30ad54c57ac70`.

Финальная проверка переключателя окон выполняется на клавиатуре после
сборки в GitHub Actions и прошивки: native-тест проверяет события прошивки,
но не поведение ОС.
